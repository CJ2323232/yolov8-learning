# 旧标准版 → 新标准版：数据治理与训练协议变化

更新：2026-10-23。项目有两条证据线：本页记录数据与流程改进；[标准版→P2报告](p2_training_comparison/README.md)记录新划分上的结构对照。两者回答不同问题。

## 三个数据阶段

| 阶段 | train / val / test | 说明 |
| --- | --- | --- |
| 历史模型使用的原划分 | 6064 / 758 / 759 | 已发现跨分区重复，分数保留作历史记录 |
| 首轮内容去重与冲突隔离 | 6005 / 750 / 752 | 隔离37组74张冲突标注版本，形成7507张接受图片 |
| 当前保守场景风险隔离 | 6488 / 511 / 508 | 保留7507张，491张变更分区，已检索关联不再跨分区 |

后两个阶段比较：20,466对候选跨分区关系降到0；人工确认同组的10对跨分区关系降到0；PartA验证/测试206/200张降为0/0。候选共涉及2,126张图片，不能将候选对数表述为确认泄漏数。可重算证据见[隔离报告](scene_isolation/README.md)。

## 旧、新标准版的设置

| 项目 | 旧标准版 | 新标准版 |
| --- | --- | --- |
| 数据 | 原历史划分 | 保守场景风险隔离版本 |
| 模型结构 | YOLOv8n标准结构 | YOLOv8n标准结构，nc=2固定配置 |
| 目标轮数 / 输入尺寸 | 50 / 640 | 50 / 640 |
| batch | 4 | 2 |
| optimizer配置 | auto | AdamW |
| lr0配置字段 | 0.01（auto下不能视为实际采用值） | 0.001667 |
| momentum配置字段 | 0.937（auto下不能视为实际采用值） | 0.9 |
| seed / nbs | 0 / 64 | 0 / 64 |
| lrf / weight_decay | 0.01 / 0.0005 | 0.01 / 0.0005 |
| mosaic / close_mosaic | 1.0 / 10 | 1.0 / 10 |
| scale / translate / mixup | 0.5 / 0.1 / 0 | 0.5 / 0.1 / 0 |
| 预训练加载证据 | 历史配置记录pretrained，缺少当前逐层加载审计 | 仅共有层0..15，210状态张量，记录并核验加载哈希 |
| 设备过程 | Mac MPS历史训练 | 前13轮Mac MPS，随后Windows CUDA续训 |

旧记录：[args.yaml](training/helmet_50/args.yaml)、[results.csv](training/helmet_50/results.csv)。新记录：[有效参数](p2_training_comparison/standard/effective_args.json)、[初始化](p2_training_comparison/standard/initialization.json)、[CSV](p2_training_comparison/standard/results.csv)、[迁移事件](p2_training_comparison/standard/migration_events.json)。

旧optimizer=auto，不能仅比较配置字段就称“学习率从0.01降到0.001667”或断言换了实际优化器。两份CSV中三组参数学习率在以下轮次相同：

| 轮次 | 旧、新记录共同的lr/pg0、pg1、pg2 |
| --- | ---: |
| 13 | 0.00127092 |
| 40 | 0.000379743 |
| 50 | 0.0000496766 |

batch、数据量、初始化覆盖和设备过程的差异仍需披露，不能把相同轮次的学习率相同理解为训练全过程等价。

## 已证明什么，以及如何表述

已量化的贡献是：保留7507张有效样本、调整491张分区，使固定检索候选中的跨分区关系从20466对降到0，并保留清单和核验流程。这提高了对已知风险的控制和实验可追溯性。

未知同源关系仍可能存在；PartA全部进入训练集使当前验证/测试不覆盖新教室。旧、新标准版训练和评价图片同时变化，不能把分数差归因于某一项数据治理措施。旧模型在重新划分的评价图片上可能已有训练暴露，也不能直接当作新划分的独立对照。

当前无需为了展示数据治理价值再次训练。优先使用新标准版和P2现有权重，在同一验证集完成固定阈值、尺寸分层和耗时对比；若以后要研究“数据治理对模型泛化的独立影响”，需要另外设计共同、未暴露的评价集及受控训练协议。

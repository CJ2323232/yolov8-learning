## 数据与初始化

当前6488/511/508划分，共7507张。清单SHA256：
`5781ecdffa173010f539189b15565220f5e2ac597b5f8ea72f5cf7b1e8bf63e4`。

重建时核对清单、图片、标注、隔离约束，不能重新随机拆分后沿用原成绩。已检索风险隔离不等于穷尽所有场景关系。类0是戴帽头部，类1是未戴帽头部。[划分证据](../reports/scene_isolation/README.md)。

标准/P2采用官方YOLOv8n共有层0～15迁移策略。CBAM沿用P2初始化，逐张量核对所有非CBAM状态；不从已训练50轮的P2 best.pt继续微调。[固定训练协议](../models/configs/p2_cbam_training_protocol.json)。

## 环境

应用本机验证环境为Python3.14.7、torch2.14.0、Ultralytics8.4.164、Gradio6.30.0；requirements只固定直接依赖，不是完整跨平台环境锁。

CBAM正式对照要求原Windows环境：Python3.10.10、torch2.14.0+cu126、Ultralytics8.4.164、同一RTX3060。保留原环境，不通过升级依赖或自动降低batch应对问题。训练入口核对67项原参数、数据和初始化；环境或显存检查失败时先解决原因。

历史标准版前13轮MPS后CUDA续训；P2为CUDA。历史环境未完整锁定，不作严格的单变量因果结论。单次训练也不足以证明稳定增益。

## 轻量代码检查

安装项目依赖后，在项目根目录运行：

```bash
python -B -m unittest tests.test_fusion_app -v
python -B -m unittest tests.test_p2_cbam tests.test_cbam_training tests.test_cbam_update tests.test_helmet_models -v
```

部分历史产物检查在缺少本地数据时会跳过；测试通过不代表完成CUDA训练或取得新的精度成绩。游戏本上用 `python -B train_p2_cbam.py --check` 做实际预检，正式训练步骤见[训练说明](P2_CBAM_TRAINING.md)。

## 评价纪律

- 验证集选配置，记录后再评价测试；本项目测试集已历史使用，不能称为全新外部盲测。
- 区分mAP与固定阈值P/R/F1；未匹配预测不一律等于人工确认误检。
- 同时报类别、尺寸、失败情况和速度；记录硬件、线程、预热、计时范围。
- 模块对比固定数据、初始化、输入、batch、优化器、增强、轮数与种子。新结果保存到新目录，不覆盖旧证据。
- CBAM是否有效，要等正式训练与同条件评价；需要更强结论再做多种子对照和新场景评价。
